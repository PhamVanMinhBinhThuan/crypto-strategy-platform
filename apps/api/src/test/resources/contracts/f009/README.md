# Fixture contract F-009

Các fixture này khóa representation công khai cho Market, Dataset và Strategy.
Mọi decimal cần độ chính xác tuyệt đối được biểu diễn bằng JSON string; timestamp dùng
UTC; business identifier là opaque scalar. Fixture không chứa owner ID, secret,
provider payload hoặc chi tiết storage nội bộ.
