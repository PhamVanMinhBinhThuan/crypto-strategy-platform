# F-012 UI Reference Mapping

## Feature

F-012 owns the browser business UI for Market, Strategy and News on top of F-011 frontend foundation.

## Shared references

### UI-01 — Market Dashboard

- Screenshot: `../screens/Market Dashboard.png`
- Page source: `../prototype/pages/MarketDashboardPage.tsx`
- Components: `../prototype/components/market/`
- Production route: `/market`

Reference intent:

- market/context controls;
- multi-timeframe analytical layout;
- market connection/state placement;
- chart density and hierarchy.

Production authority remains the released Market/Data public contracts and F-011 clients.

### UI-02 — Strategy Composer

Do not treat prototype-only AI/experimental concepts as approved F-012 scope unless a feature specification explicitly includes them and a released public contract exists.

## Foundation rule

F-012 must reuse F-011 shell, auth/session, HTTP/realtime clients and shared states. The prototype navigation/layout files are visual evidence only.
