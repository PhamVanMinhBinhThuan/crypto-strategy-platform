# Architecture Diagrams

Thư mục này lưu source diagram nếu không dùng Mermaid trực tiếp trong Markdown.

## Tên file đề xuất

```text
system-context.drawio
container-view.drawio
module-view.drawio
deployment-view.drawio
historical-sequence.drawio
realtime-sequence.drawio
backtest-flow.drawio
search-flow.drawio
news-sentiment-flow.drawio
```

## Quy tắc

- Commit source diagram, không chỉ ảnh export.
- Nếu export, dùng cùng tên với source (`.png` hoặc `.svg`).
- Cập nhật diagram và tài liệu Markdown trong cùng Pull Request.
- Ưu tiên Mermaid nếu diagram đơn giản.
