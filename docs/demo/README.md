# Demo Documentation

Thư mục này chuẩn bị toàn bộ nội dung cần thiết để demo ổn định, có thể lặp lại và có phương án dự phòng.

## Danh sách file

| File | Mục đích |
| --- | --- |
| `demo-script.md` | Kịch bản demo theo từng bước |
| `demo-checklist.md` | Checklist trước, trong và sau demo |
| `demo-data.md` | Pair, timeframe, dataset và parameters cố định |
| `troubleshooting.md` | Lỗi thường gặp và cách xử lý |
| `fallback-plan.md` | Phương án khi Binance, News hoặc service lỗi |
| `presentation-outline.md` | Phân chia phần trình bày cho thành viên |

## Quy tắc

- Demo bằng commit/tag đã tổng duyệt.
- Không dùng secret thật trên màn hình.
- Dữ liệu và parameters phải cố định sau buổi tổng duyệt.
- Mọi external dependency phải có phương án fallback.
